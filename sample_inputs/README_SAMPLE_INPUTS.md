# Sample Inputs

This folder can hold optional sample banana images or notes for testing the local Gradio app.

Recommended manual values for a quick first run:

```text
weight_g = 120
surface_temp_C = 27
ambient_temp_C = 26
relative_humidity_pct = 55
pressure_hPa = 1013.25
gas_resistance_kohm = 80
```

Upload one clear banana image with a mostly plain background, then click `Predict Grade`.
